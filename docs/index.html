产品概览

它不是一个简单画笔悬浮层，而是一套面向讲解现场的操作系统外覆盖界面

以下所有内容都基于当前实际代码能力整理，只讲已经实现的功能、已写进交互的细节和真实存在的优势。

传统做法的问题

  • 在 PPT、白板、截图工具、录屏工具之间来回切。
  • 一旦切窗口，观众注意力和讲解节奏都会断。
  • 双屏或投屏时，批注常常不在正确屏幕上。
  • 临时讲解结束后，结果很难快速沉淀为图片。

ScreenAnnotator 的处理方式

  • 用透明全屏覆盖层把大多数讲解动作收进同一界面。
  • 把桌面、放映页、冻结画面和白板都作为批注载体。
  • 把穿透、保存、撤销、白板页、锁屏这些高频动作做成就近入口。
  • 把输出结果直接合成为 PNG，减少二次整理。

因此它更适合

  • 要边展示边解释，而不是展示完再回头补说明的人。
  • 需要多屏演示、放映联动和临场板书的人。
  • 想把讲解结果保存下来的人。
  • 希望少折腾工具链、直接开始讲的人。
界面形态

官网宣传最该强调的一点：它看起来轻，但能力不轻

平时收成一个悬浮球，需要时再展开成分组工具栏，演示模式还会自动换成更适合放映场景的停靠布局。

平时状态

收拢为悬浮球

降低屏幕侵入感，让桌面和被讲解内容保持主角位置。

操作状态

展开为分组工具栏

书写、擦除、形状、颜色、粗细字号、白板设置都有单独入口，避免一屏堆满按钮。

演示状态

底部停靠

检测到放映后，工具栏会更贴近当前放映屏的底部区域，减少遮挡和鼠标移动距离。

这套界面布局为什么合理

  • 讲解时视觉中心始终在你的内容上，而不是在一块巨大工具面板上。
  • 高频动作靠前，低频配置放进子面板，既快又不乱。
  • 白板模式和演示模式会影响工具栏展开行为，尽可能符合当下使用场景。
  • 状态消息用底部胶囊提示，反馈明确但不过度打扰。
完整功能

从落笔到导出，所有关键能力都已经串起来了

这部分按真实使用频率和用户感知价值来编排，不只是把按钮名字列一遍。

画笔

适合快速书写、手绘指引、手写框图，笔迹会做动态平滑处理，减轻手抖感。

荧光笔

半透明高亮，默认更宽，更适合扫重点、涂区域、强调关键词，不会像实线那样压住内容。

文本输入

支持点击落点、多行文本、字号调整、颜色调整、双击重编、拖拽移动，非常适合给流程和截图补说明。

直线

适合结构说明、连接关系、指向重点和页面间逻辑串联。

高级箭头

采用更强视觉感的锥形实心箭头，不是生硬的默认箭头，更像专业演示标记。

矩形框选

圆角边框风格，更适合现代界面、网页和软件窗口的重点圈定。

椭圆圈选

适合圈头像、按钮、局部模块、图表点位和散点区域。

虚线直线

更适合辅助说明、参考路径、非最终结论和补充提示。

绘制层面的隐藏价值

  • 不同类型笔迹有不同的点采样和速度平滑策略，兼顾顺滑感与性能。
  • 拖拽中的形状会实时预览，避免“先画再发现不对”。
  • 文本框会根据内容和字号自动测量尺寸，并自动保持在可视范围内。
  • 导出时会按更高像素比生成 PNG，兼顾清晰度与实际使用效率。
修正能力

现场讲解最值钱的不是不出错，而是出错后能快速修正

这款软件在“删改”上做得比很多只会清空画布的工具细得多。

对象橡皮

点中某个对象就删除整个对象，适合快速移除一段文字、一条线或一个形状。

笔画橡皮

以擦写方式局部抹掉笔迹，适合只擦错的一截，不用整条重画。

圈选擦除

自由圈出一片区域，把范围内对象整体清掉，适合清理一大团临时笔记。

撤销 / 重做

每个上下文都维护独立历史栈，意味着桌面批注、白板页和不同放映页都能各自回退。

当前页清空与全局清空

既支持只清当前上下文，也支持一键清空全部覆盖批注、所有白板页和冻结底图，适合不同节奏的重置需求。

演示联动

PowerPoint 与 WPS 联动，是它从“画图工具”升级为“演示辅助系统”的关键

不是单纯把画布盖在 PPT 上，而是尽量理解你现在正在放映什么、在哪块屏幕、是哪一页。

自动识别放映窗口

通过窗口信息、标题特征、前台状态、进程名与 COM 对象等多重方式综合判断，尽量稳定识别放映状态。

识别当前页与总页数

联动成功后可显示页码状态，让讲师知道自己正在给哪一页加批注。

跟随放映显示器

会找到放映窗口所在显示器，把工具栏停到更合适的位置，减少讲解时来回找工具。

按页隔离批注

不同演示页的批注不会互相污染，翻页相当于切换到另一套独立上下文。

对讲课和汇报意味着什么

  • 双屏时不需要反复猜哪个屏幕是当前展示屏。
  • 翻页后不容易把旧批注错留在新页面。
  • PowerPoint 与 WPS 都兼顾，适应真实办公环境。
  • 联动监测带有稳定策略与轮询兜底，降低偶发识别抖动。

截图与白板

既能对真实画面做讲解，也能随时切进纯净白板

这两种模式把“讲现有内容”和“补充新内容”无缝接在一起，是宣传页里最值得展示的能力之一。

截图冻结模式

一键抓取当前显示器内容作为冻结底图，再在它上面继续讲。特别适合先定格一个复杂界面，再慢慢拆解结构。

  • 截图时会临时隐藏覆盖层，避免把自己的工具栏截进去。
  • 冻结后仍可继续画线、加字、擦除、撤销、重做。
  • 最终导出的是底图与批注的合成结果，便于直接分享。

白板模式

一键切纯色背景，把桌面干扰全部拿掉。适合讲思路、列步骤、板书公式、拆流程和临场补充说明。

  • 支持开启与关闭白板。
  • 支持新增白板页，以及上一页、下一页切换。
  • 支持预设色盘、最近使用颜色和系统色盘取色。
  • 每一页白板都保留独立批注内容，适合章节化讲解。

穿透模式

覆盖层可把鼠标事件交给下层窗口，同时保留对工具栏区域的重新唤醒能力，边讲边操作原软件更顺。

即时状态胶囊

保存成功、联动切换、白板开关、清除动作、穿透开关都会即时提示，降低不确定感。

低性能设备照顾

检测到较弱硬件时会启用低延迟策略，降低像素比与阴影开销，优先保住流畅性。

可选阴影效果

想要更强层次感时可以开阴影，想要更干净更轻时可以关掉，适应不同机器和不同展示风格。

颜色与粗细统一管理

常用颜色直接点选，线宽与文字大小可快速滑动调整，适合临场快速响应。

文本支持拖拽与重编

文字不是一次性贴纸，后续仍然可以选中、改色、改字号、双击再编辑、拖到更合适的位置。

FAQ

用户最关心的几个问题

这些问题在宣传页里很重要，因为它们往往决定用户第一眼能不能理解产品价值。

它只能在桌面上画吗？

不是。它既能直接覆盖桌面，也能在 PowerPoint / WPS 放映时联动对应页，还能把当前画面冻结为底图继续讲，或者切成纯白板模式。

多屏时会不会很乱？

不会。它会获取完整显示器布局，还支持联动显示器和手动锁定显示器，适合双屏讲课和扩展桌面演示。

讲完能留结果吗？

可以。当前舞台可直接导出为 PNG，包含底图、白板背景和批注内容，适合会后发送或归档。

低配机器能不能用？

软件内置低性能模式检测策略，会在需要时减少部分高开销视觉效果，优先保证响应速度和可用性。

ScreenAnnotator 的真正卖点，不是一堆按钮，而是讲解过程终于完整了

你可以直接在展示内容上说清重点，在需要操作原界面时穿透下去，在需要停住画面时冻结，在需要拓展说明时切白板，在需要保存时直接导出。这种连续感，才是它最像一款成熟产品的地方。
